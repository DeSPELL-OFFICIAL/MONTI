## 2. "최소 행사 ≤ 6탭" 제안

**현재 실측(동아리 공연·내일 저녁·무료 30명)**: 포스터 올리기→파일선택→크롭확정(3) + 제목 포커스+타이핑(4) + 소개 10자 타이핑(5) + 장소 타이핑(6) + 시작 datetime 처음부터 지정(날짜·시·분 ≈ 7~11) + 수량 100→30 지우고 입력(12) + 만들기(13) + done의 "지금 발행하기"(14). → **약 14탭·30+타건**, 두 화면. 기준선 미달.

**제안(기본값·문구까지)** — 서버가 이미 허용하는 값들이라 안전(빈 소개 `organizer.ts:206-212`, 포스터/장소는 화면 규칙일 뿐):
1. **포스터 선택제 + 자동 생성**: 없으면 제목+선택 테마색으로 포스터 자동 합성(티켓 그림 프리셋 12종 재사용). `eventProblems` 99행에서 `poster` 필수 제거. → 3탭+대기 제거. (Luma·Wallet 선례)
2. **시작 기본값 = 다음 주말 19:00**: `emptyEventDraft.startsAt`(useEventDraft 67)을 0 대신 "다음 토요일 19:00"으로. 종료는 이미 +2h 파생. `datetime-local`에 `min=지금` 부여로 과거 선택 인라인 차단. → 시작 지정 탭(가장 무거움) 제거.
3. **장소 "온라인/미정" 기본 옵션**: 지역 select 옆 "장소 미정" 칩 1탭, 또는 venue 필수 완화. → 1탭.
4. **소개 최소 10자 완화**: 아래 §3 참조 → 타이핑 제거.
5. **수량 빠른 칩(30·50·100·무제한)**: 티어 카드 수량 위 1탭 칩. → "30명"이 1탭.

**결과 흐름**: 제목 타이핑(1탭) → 수량 30 칩(1탭) → (선택)장소 미정 칩(1탭) → 만들기(1탭) → 지금 발행하기(1탭) = **4~5탭**. 포스터·시간·소개·종료·주최자명 전부 유효 기본값. 기준선 충족.

## 3. 검증·에러 문구 재작성

- **소개 10자 최소(draftRules 21·115, copy 370)**: 중학생 혼자 완주 기준에선 마찰. **완화 권고** — 필수 해제(빈값 허용), 대신 예시 placeholder를 강하게: `bodyPlaceholder='예: 우리 동아리 정기공연이에요! 친구들 다 놀러 와요 🎸'`. 타이핑을 하되 <10자여도 통과. (`bodyTooShort` 규칙·문구 삭제)
- **1인당 한도(copy 512)** "…1장에서 **65535**장 사이로…" → uint16 폭 누수. **"한 명이 몇 장까지 받을 수 있는지 정해 주세요 (보통 1장)"**.
- **번호 오류(ko 25)** "번호를 다시 확인해 주세요." → **"번호를 다시 확인해 주세요. 예: 01012345678"** (형식 제시).
- **양도 마감(copy 513)** "…0시간 이상으로…" → **"양도를 언제까지 받을지 정해 주세요. 행사 시작 몇 시간 전인지 숫자로요 (예: 2)"**.
- **주최자 이름 도움말(copy 361)** "나중에 바꿀 수 없어요." → 프리필 칸에 겁주는 경고. **"행사 화면에 이 이름이 보여요"**로 완화, 불변 경고는 (i) 툴팁으로.
- **숫자칸 빈칸→0 강제(TierCard 199-205·227-240, whole())**: 수량칸을 지우면 "0"이 박혀 "30" 입력 시 "030" 등 꼬임. 편집 중엔 빈 문자열 허용(별도 문자열 버퍼), blur/제출 시 검증. **실사용 버그.**
- **자동 포커스 부재**: 전화 번호칸·제목칸에 `autoFocus` 없음 → 매 화면 1탭 손해. 첫 주요 입력에 포커스 권고.
- **제목==입력 라벨 중복(페르소나 S3)**: 전화(Phone 63·74)·인증(Verify 118·120)에서 Screen 제목과 Field 라벨이 글자까지 동일. Field 라벨을 짧게("휴대폰 번호"/"인증번호") 하거나 시각 라벨 숨김.

*맥락: 페르소나 라이브4의 최상위 실차단은 가입 첫 관문 reCAPTCHA 이미지 챌린지(S1)와 연속 claim op 미재전송(S1)이며, 이는 폼 렌즈 밖(인증 게이트·온체인)이나 "혼자 끝까지"를 실제로 막는 지점이라 병기.*
