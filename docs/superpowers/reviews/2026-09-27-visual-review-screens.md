# MONTI 웹앱 시각 리뷰 — 실기기 스크린샷 (2026-09-27)

대상: https://monti.despell.io · 뷰포트 390×844(360×740 1패스) · 캡처 15장.
기준: Toss식 명료함, Apple식 타이포/여백, 퍼플+반투명, "중학생도 3초 안에 다음 행동을 안다".
평가 관점: 위계·정렬·여백 리듬·대비·잘림·빈공간·버튼 존재감·카피 길이·아이콘 일관성·글래스 과용.

> 캡처 주의: 코어 페르소나 스위트가 동시 실행 중이어서 일부 화면이 로딩/시트 상태로 잡혔다.
> 상단 우측에 별도 내비 크롬은 코드상 없음(내비는 하단 탭바 단일) — 관련 지적은 제외.

## 10·11 탐색 (signed-out / signed-in) — `10-discover-signed-out.png`, `11-discover-signed-in.png`
두 화면 동일. 검색 + 날짜/지역/테마 드롭다운 3개가 첫 화면을 다 차지하고, 그 아래는 스켈레톤만.
- 문제: 이벤트 목록이 끝내 로딩(스켈레톤)으로 캡처 — 라이브 로딩 속도 점검 필요, 실제 카드 디자인 평가 불가.
- 문제: 필터가 세로를 과점해 콘텐츠가 폴드 아래로 밀림. 지역·테마는 chip/접이식이 적합.
- 문제: `행사 만들기` FAB가 스켈레톤 카드 위에 겹침(빈 목록 탓). 로딩 종료 후 재확인.
- 좋음: 타이틀·검색 라벨 위계 깔끔, 퍼플 FAB 존재감 명확.

## 12 행사 상세(홀더) — `12-event-detail-holder.png`
`탐색` 헤더 + 스피너만. 상세가 로드되지 않음(사실상 캡처 실패). 홀더용 상세는 별도 재확인 필요.

## 13 행사 상세(비홀더) — `13-event-detail-non-holder.png`
설명 글래스 카드 + 날짜 + `지도로 보기` + 티어행(일반 · 91자리 남음) + `티켓 받기`/`공유`.
- 문제: 하단 절반이 빈 공백. 콘텐츠 상단 쏠림, CTA가 본문에 떠 있어 리듬이 끊김 → StickyBar 권장.
- 문제: 포스터/히어로 이미지 부재로 텍스트만의 밋밋한 상세. 티켓아트/포스터 히어로 추가 여지.
- 문제: 날짜에 요일 없음("2026. 9. 29. 오후 12:00"). 좋음: 위치 링크·티어행 구조 명료.

## 14 티켓 받기 시트 — `14-claim-sheet.png`
바텀시트: 티켓 종류 드롭다운(일반) + `티켓 받기` + "무료예요 · 돈 안 들어요" + `닫기`.
- 문제: 티어 1개인데 드롭다운으로 마찰. 단일 티어면 정적 표시.
- 문제: 전체폭 `닫기` 버튼이 primary와 시각적으로 경쟁 → grabber/텍스트 버튼으로 낮추기.
- 문제: "무료예요 · 돈 안 들어요"는 같은 뜻 반복. 카피 1개로.

## 15 내 티켓 — `15-tickets-list.png`
행: 좌측 티켓아트 썸네일 + 우측 "#28 · 입장 전".
- 문제(핵심): 행 텍스트가 토큰번호+상태뿐. 행사명이 썸네일 안 작은 글씨로만 존재 → 위계 역전.
- 문제: 그리드 `76px 1fr`에 짧은 텍스트라 우측 대부분이 죽은 흰 공간. 카드 과대.
- 문제: `입장 전` 반복 텍스트 → 상태 chip으로. 날짜가 행에 없음.

## 16 티켓 상세 — `16-ticket-detail.png`
프리미엄 티켓아트 히어로는 훌륭. 하지만 하단 액션이 무너짐.
- 문제(최우선): 주 액션 `입장하기`가 작은 FAB, 부 액션 `친구에게 주기`가 전체폭 → 주·부 역전.
- 문제: FAB가 전체폭 버튼 우측에 겹쳐 잘린 듯 지저분. `탐색` 링크는 버튼 위에 외톨이.

## 17 프로필 — `17-profile.png`
인증 카드 + 표시이름 + 별명 + 언어.
- 문제: 동일 강도 primary `저장` 버튼 2개(표시이름/별명) → 위계·혼란. 강도 차등 또는 통합.
- 문제: 표시이름 설명이 2문단 벽. 3초 원칙 위배 → 1문장으로.
- 문제: 본인인증/저장/저장 퍼플 버튼이 세로로 쌓여 강조가 균질.

## 18 본인인증 — `18-verify.png`
카피는 명료("30초면 끝나요"). 버튼 위계 좋음.
- 문제: 화면 80%가 공백, 상단에 버튼 2개만 → 미완성 인상. 안내 리스트/일러스트 or 수직 중앙/하단 고정.

## 20 주최자 홈 — `20-organizer-home.png`
우리 팀(스피너) · 내 행사(빈) · 행사 번호로 열기 · `만들기` FAB.
- 문제: `내 행사` 빈 상태 미처리(빈 카드). `우리 팀` 로딩. 빈 상태 컴포넌트 필요.
- 문제: `만들기` FAB가 반투명이라 비활성처럼 보임 → 로딩 중에도 enabled/명확한 disabled 근거.
- 문제: `행사 번호로 열기`(파워유저 기능)가 `내 행사`와 동급 카드로 과대 강조.

## 21·30 만들기(폼) — `21-create-top.png`, `30-create-360.png`
두 캡처 모두 `이어서 작성할까요?` ResumeSheet가 폼을 덮은 채 잡힘(freshScene 미해제). 클린 폼 미확인.
- 문제: 틴트 배경 위 glass 섹션 안에 다시 반투명 필드 → 글래스 중첩으로 대비 저하.
- 360px: 구조적 가로 오버플로 없음, 텍스트 정상 줄바꿈. (단 시트에 가려 완전 검증 불가)

## 22 만들기(티켓 그림) — `22-create-tickets.png`
티켓아트 프리셋 가로 캐러셀(선택=퍼플 링) 좋음. 프리뷰 카드 프리미엄.
- 문제: ResumeSheet가 하단을 덮어 프리셋 라벨(`오로라`)이 잘림. 시트 미해제 상태 캡처.

## 24 생성 완료 — `24-created-publish.png`
세그먼트(만들기/공개) + 초록 체크 + `지금 공개하기` + 링크 2개.
- 문제: "아직 아무에게도 안 보여요"가 disabled 입력창처럼 렌더 → 상태 텍스트/chip으로.
- 문제: 초록 체크가 퍼플 테마에서 튐(브랜드 성공색 검토). `이름 없는 행사` 축하화면에 노출은 어색(테스트 데이터).
