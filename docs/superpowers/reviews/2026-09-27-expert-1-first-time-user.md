# UX 전문가 1 — 첫 사용자(중학생) 관점 리뷰

기준: "중학생도 혼자 끝까지 쓸 수 있어야 한다". 렌즈 = 처음 온 14세. 화면마다 3초 안에 "지금 뭘 눌러야 하지?"가 보이나.
방식: (A) 친구 링크 → 행사 → 티켓 받기 → 내 티켓, (B) 동아리 공연 만들기 → 링크 배포 → 신청 승인, 두 여정을 14세로 걸어봄.
소스: `apps/web/src/**`, `shared/copy/ko.ts`, `organizer/copy.ts`, e2e 리뷰 3종, 라이브런 리포트. (코드는 mvp-web ca9c8d7 읽기전용.)

판정 한 줄: **문장 톤·오류복구는 이 나이대에 이미 좋다. 남은 벽은 "낯선 낱말"(양도·발행·공개기록·주최사)과 "번호를 이름처럼 보여주는 자리"다. 대부분 카피 한 줄 교체로 해결된다.**

## 임팩트/노력 Top 10 (고임팩트·저노력 순)

1. **티켓 상세 제목 `#4` → 행사 이름.** 내 티켓의 첫인상이 무의미한 숫자. `tickets/Detail.tsx:57`
2. **`양도` → `친구에게 주기`(전 화면).** 14세가 절대 안 쓰는 단어. `ko.ts:123,148`, `tickets/Detail.tsx:70`
3. **`발행` → `공개하기`(주최자 전반).** "만들기≠발행" 함정의 핵심 단어. `copy.ts:69,288,453`
4. **관람객 화면의 `공개 기록`(블록체인 익스플로러 링크) 삭제/개명.** web3 누수 + 14세엔 무의미. `ko.ts:101,274`
5. **탐색 FAB `만들기` → `행사 만들기`.** 관람객 혼란 제거. `ko.ts:85`
6. **`만들었어요` 화면 문구 강화 + `지금 공개하기` 유지.** 발행 안 하면 아무도 못 받는 함정 방지. `copy.ts:451,453`
7. **`표시 이름 vs 별명` 안내 한 줄로 축약.** 지금은 벽 같은 문장 2개. `ko.ts:236`, `me/Profile.tsx:99-100`
8. **`주최사` → `우리 팀`.** 회사 만드는 느낌 제거. `copy.ts:20,49-50`
9. **가입 중 "브라우저 입장 불가" 안내를 완료 후로 이동.** 흐름 중간 갑툭튀. `ko.ts:52`, `signup/Register.tsx:357`
10. **티켓 받기 실패에 자동 1회 재전송 + 큰 [다시 받기].** 라이브4에서 2번째 사용자부터 그냥 실패(복구 불가 체감). `claim/Claim.tsx`, `ko.ts:135` (※코드, 고노력이지만 최고 사용자 임팩트)

부록 — 잘 된 점: 오류/재시도 문구가 원인별로 셋(연결/못가져옴/없음)으로 정직, "MONTI가 대신 내요" 가스대납 안내, 가입 "한 번만 누르면 끝", 자동저장·이어작성. 톤은 이미 이 나이대에 맞다.
