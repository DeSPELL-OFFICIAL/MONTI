## 이번 실행에서 하니스가 고쳐야 했던 것 = 라운드2 UI가 바꾼 셀렉터 (제품이 아닌 하니스 수정)

라운드2("motion + Apple-like polish")로 생성 화면 DOM/모션이 바뀌어 하니스 셀렉터 3곳이 깨졌다.
`apps/web/e2e/utils/organizer.ts` 만 수정(앱 무수정). 각 항목은 실사용자에게도 잠재 마찰이다.

1. **[하니스·R2] 이어서 작성 시트 뒤 생성 화면이 `inert`.** `CreateEvent` 가
   `<div className="scene" inert={asking}>` 로, 이어서 작성 시트(모션 Sheet, 스프링 상승)가 떠 있는
   동안 **화면 전체가 조작 불가**다. 기존 `addLocatorHandler` 는 스프링·inert 와 싸우며 무한 루프에
   빠졌다 → **명시적으로 `이어서 작성하기` 를 DOM 클릭하고 시트가 사라질 때까지 대기**로 교체.
   (실사용자 함의: 초안이 있으면 결정 전까지 화면이 잠기고, 시트가 스프링으로 떠서 첫 탭이 미끄러질 수 있음.)
2. **[하니스·R2] 포스터 모달이 `showModal()` + 파일 입력의 접근성 이름 미부여.** 포스터 피커가
   `<dialog open>` → `showModal()` 로 바뀌고, 파일 입력이 `<label class="field">`(Field.tsx) 로만
   감싸져 있어 크로뮴이 라벨 텍스트를 입력의 접근성 이름으로 안 붙인다 → `getByLabel('사진 고르기')`
   미해결 → `dialog.poster-modal input[type="file"]` 로 교체.
3. **[하니스·R2] 배경 포스터 업로드 재렌더로 필드가 "not stable".** 포스터 업로드가 화면 뒤에서
   돌며 레이아웃을 계속 재렌더 → `getByLabel('소개')` 등 필드 fill 이 안정성 게이트에서 멈춤 →
   구조적 로케이터(`label.field` + 라벨텍스트) + `fill(v, { force:true })`, 프리셋 버튼은 DOM 클릭으로 교체.
   (실사용자 함의: 업로드 중 필드 입력이 살짝 튀거나 지연될 수 있음.)

## 실제 제품 결함 (심각도순)

1. **[S1·라이브·치명] createEvent 온체인 op 가 채굴되지 않음 — 수수료 수정 미반영.**
   생성 화면을 끝까지 채우고 `행사 만들기` 를 눌러도 완료(행사 주소) 화면으로 못 넘어간다. **온체인 증거**:
   createEvent op `0x3342d6adb2ee5e60215ca6a574d51448715b5d1cda0315b4ac5b25dfc2fa06d3`
   (발신 관리자 계정 `0x5DBdca2d21016936C07695FB387538094Bd372ec`) —
   - `maxFeePerGas` = **122 gwei** (지난번과 동일, "포함 가능한 수수료"로의 수정이 배포에 미반영),
     `maxPriorityFeePerGas` 2 gwei, `preVerificationGas` 1,948,443.
   - Alchemy `eth_getUserOperationByHash`: 번들러엔 접수됐으나 `blockNumber` null,
     `eth_getUserOperationReceipt` null → **멤풀 접수만, 채굴 안 됨.**
   - 인덱서 `e6b82a8` 는 여전히 행사 1건(id=1 시드, 발신 `0x509ed8…`); 관리자 계정의 온체인 행사 0건.
   가입의 온체인(registerIdentity/로그인)은 되는데 **조직/행사 생성 op 만** 채굴 문턱을 못 넘는다.
2. **[S1·라이브] 6분+ 재시도해도 확정 불가 → 뒤 시나리오 전부 블록.** UI 는 45초 뒤 정직하게
   "다시 시도/나중에 확인"을 주지만(개선), op 가 안 실리니 아무리 눌러도 완료 불가 → b·c·e·d·f 연쇄 블록.
3. **[S2·라이브] "확인 중" 대기 시간이 길다(6분+).** 45초 캡 문구는 좋아졌으나, 근본적으로 op 가
   채굴돼야 끝나므로 수수료 문제 해소 전까진 체감 대기가 무한에 가깝다.
