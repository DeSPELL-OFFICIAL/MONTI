대상: 프로덕션 `https://monti.despell.io` (mvp-web a05f379 + 01c 컨트랙트 + 승인모드 on + 새 인덱서).
방식: Playwright 헤드리스, 390×844, ko-KR/Asia-Seoul, `monti:e2e` 캡차 우회 + WebAuthn 가상 인증자.

범례: (라이브)=이번 실행에서 실제로 관찰 · 심각도 S1(치명)~S3(경미).

## 하니스가 넘으려고 추가한 우회책 = 그대로 제품 결함

각 항목은 "하니스가 이걸 넣어야 겨우 통과했다 = 실사용자는 여기서 막히거나 헤맨다" 이다.

1. **[S1·라이브] 행사 생성 온체인 작업이 끝나지 않음.** `행사 만들기` 를 누르면 화면이
   "만드는 중이에요. 화면을 나가도 돼요. 잠시 뒤 주최자 화면에서 확인해 주세요" 상태로 들어간
   뒤, **7~8분간 재시도(버튼 재클릭)를 반복해도 완료 화면(행사 주소)으로 넘어가지 않았다.**
   서명 없는 대기(확인 중)만 지속 → 주최자는 행사가 만들어졌는지조차 알 수 없다. (하니스 우회:
   "확인 중" 재클릭 루프 6분 — 그래도 실패.) createEvent 옵(페이마스터/번들러/01c)의 확정이
   앱의 대기·재확인 창보다 훨씬 느리다. **가입의 온체인(registerIdentity)은 완료되는데(스모크
   통과), 조직/행사 생성 경로만 확정이 안 된다** — 경로 특정 문제.
2. **[S2·라이브] 패스키 로그인이 콜드 상태에서 간헐 실패.** 재방문 로그인(`로그인`)이 콜드
   Cloud Function 직후 "로그인하지 못했어요. 다시 시도해 주세요" 로 거절되곤 했다. (하니스 우회:
   로그인 최대 6회 재시도.) 실사용자는 첫 탭에서 실패를 보고 이탈할 수 있다.
3. **[S2·라이브] 발행(publish) 작업도 대기 초과 → "아직 확인 중이에요".** 발행 버튼을 눌러도
   영수증이 늦어 "확인 중" 에 머물러, 실제 발행 여부는 새로고침해야 확인된다. (하니스 우회:
   발행 후 대시보드를 폴링해 초안 여부로 판정.)
4. **[S2·라이브] 이어작성(resume) 시트가 수 초 늦게 떠서 입력을 가림.** 생성 화면 진입 후 파이어
   스토어 초안 읽기가 끝나면 "이어서 작성할까요?" 시트가 **뒤늦게** 떠 소개/필드 입력을 가로챈다.
   (하니스 우회: 시트 자동 감지·닫기 핸들러.) 실사용자는 타이핑 중 갑자기 시트가 덮치는 경험.
5. **[S2·라이브] 포스터 크롭 모달이 `<dialog open>`(showModal 아님)이라 확인 버튼이 정상
   클릭에 안 잡힘.** "이 사진으로 정하기" 가 보이지만 가시성/안정성 판정에 걸려, 프로그램적
   클릭으로만 눌렸다. 겹침/z-index 문제로 실사용자도 탭이 빗나갈 수 있다. (하니스 우회: 버튼
   click() 직접 호출.)
6. **[S2·라이브] 하단 고정 액션바가 "더 설정하기" `<details>` 에 가려 `행사 만들기` 클릭이
   가로채짐.** 스티키바의 1차 버튼이 접기 요소에 덮인다. (하니스 우회: 버튼 click() 직접 호출.)
7. **[S3·라이브] 새로고침 후 세션 재수화(rehydration) 레이스.** 전체 로드 직후 파이어베이스
   세션이 비동기로 복구되어, 그 틈에 FAB(만들기)를 누르면 익명으로 간주돼 가입 화면으로 튄다.
   또 이미 주최사가 있는 사용자는 FAB 가 생성 화면이 아니라 주최자 홈으로 간다(목적지 혼동).
   (하니스 우회: 생성 화면 직접 이동 + 재시도.)
