# 관리자 리뷰 — 페르소나 …01 "관리자 몬티" (라이브 3, 2026-09-27)

대상: 프로덕션 `https://monti.despell.io` ("S1 수수료 수정" + 라운드2 UX 반영본). 별점 1–5. (라이브)=실제 관찰.

> 작은 크루로 무료 모임 티켓을 나눠주려는 주최자. 폰(390px, 헤드리스 크로뮴)에서 진행.

## 단계별 별점

- **가입/로그인 ★★★★☆ (라이브)** — 재방문 패스키 로그인이 이번엔 **콜드에서도 첫 시도에 성공**했다
  (7.5s, 웜 7.1s). 라운드2의 로그인 자동 재시도가 실제로 붙어서, 지난번의 "로그인하지 못했어요" 튕김이
  이번 실행에선 없었다. 스모크(가입→온체인 신원등록→로그인)도 11초로 통과.
  > "이번엔 로그인이 한 번에 됐다. 지난번 불안했던 게 나아졌네."
- **행사 탐색 ★★★★☆ (라이브)** — 라벤더 UI, 필터·검색·하단탭 정상. 공개 행사 3건 노출, 상세도 정상
  ("MONTI Launch Party · 497자리 남음 · 티켓 받기").
- **행사 만들기(입력) ★★★★☆ (라이브)** — 이번엔 **생성 화면 전 구간을 끝까지 채울 수 있었다**:
  이어서 작성 시트 → 포스터 올리기/크롭("이 사진으로 정하기") → 제목·소개·시간·장소 → 빠른 시작(무료
  선착순) 프리셋 + 실시간 티켓 그림(오로라 등 12종) → 주최자 이름까지. 설계는 여전히 좋다.
  하단에 "만드는 비용은 MONTI가 대신 내요" 안내도 정직하다.
- **행사 발행/생성(확정) ★☆☆☆☆ (라이브·치명, 지난번과 동일 근본원인)** — `행사 만들기` 를 눌렀지만
  **온체인 생성이 끝내 확정되지 않았다.** 약 45초 뒤 화면이 라운드2 문구로 바뀌어
  "아직 확인 중이에요. 다시 시도하거나 나중에 주최자 화면에서 확인할 수 있어요" + `다시 시도`/`나중에 확인`
  버튼을 정직하게 보여준 것은 개선(무한 스피너 대신). 그러나 **재시도를 반복해도 6분 넘게 완료(행사 주소)
  화면으로 넘어가지 못했고**, 결국 생성 화면(`/org/new`)에 머물렀다. 온체인 근거로 확인한 바:
  createEvent 유저오퍼레이션(op)이 번들러에는 접수됐지만 **한 번도 블록에 실리지 않았다**
  (아래 총평 참고). 주최자 입장에서 "정직하게 알려주긴 하는데, 결국 행사를 못 만든다."
  > "다시 시도를 눌러도 계속 확인 중. 만들기가 안 끝난다."
- **승인 관리(신청 관리) ☆ (미도달)** — 승인 행사 자체를 생성까지 못 가서(위 문제) 신청 관리
  화면을 열어보지 못했다.

## 총평
라운드2 UX는 실제로 좋아졌다 — **로그인 자동 재시도, 45초 캡 후의 정직한 "다시 시도/나중에 확인",
사후원조(가스 대납) 문구**가 모두 라이브로 확인됐고, 생성 화면 입력 전 구간이 매끄럽게 완주됐다.
그러나 **핵심 온체인 작업(createEvent op)이 여전히 확정되지 않는다.** 온체인 증거:
op `0x3342d6ad…2fa06d3`(발신 관리자 계정 `0x5DBdca2d…Bd372ec`)의 `maxFeePerGas` 가 **122 gwei
그대로** — "포함 가능한 수수료를 낸다"던 수정이 **배포에 반영되지 않았다.** 그래서 op 는 멤풀에 접수만
되고 채굴되지 않으며(receipt null), 인덱서엔 여전히 행사 1건(시드)뿐이다. 주최자는 "만들 수는 있게
생겼는데, 마지막 한 걸음(확정)이 안 된다." 이 한 지점이 지난 라이브 2와 동일하게 뒤 흐름 전체를 막았다.
