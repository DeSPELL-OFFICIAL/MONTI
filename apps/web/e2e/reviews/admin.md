## 단계별 별점

- **가입/로그인 ★★★★☆ (라이브)** — 재방문 패스키 로그인이 콜드에서도 첫 시도에 성공(중앙값 **7.1s**, n=11). 자동 재시도가 계속 붙어 튕김 없음.
- **행사 탐색 ★★★★☆ (라이브)** — 라벤더 UI, 공개 행사 3건·상세 정상. 하단탭·필터 정상.
- **행사 만들기(입력) ★★★★☆ (라이브)** — 새 진입점 `행사 만들기`(옛 `만들기` FAB) → 이어서 작성 시트 → 포스터 올리기/크롭 → 제목·소개·시간·장소 → 빠른 시작 프리셋 + 실시간 TicketArt → 주최자 이름까지 완주. 생성 중앙값 **~18s**.
- **행사 만들기 → 공개(확정) ★★★★★ (라이브)** — 용어가 `발행`→`공개하기`로 바뀌었고, 완료 화면에서 `지금 공개하기` 한 번으로 공개+공유가 한 화면에서 끝난다(발행 전 링크·QR 숨김, 공개 후 그 자리 노출). 무료 선착순·관리자 승인 두 행사를 만들고 **공개까지** 마쳤다(공개 중앙값 ~15s). 유료는 설계대로 정직 차단(`유료 티켓은 곧 열려요…` + 버튼 비활성). **온체인**: 무료=Event 6(Published), 승인=Event 7(Published) — 인덱서 `e6b82a8` 확정.
  > "이제 만들기가 1단계, 공개가 2단계라고 화면이 알려준다. 공개하면 바로 그 자리에 초대 링크가 뜬다."
- **마감(sold-out) 관리 ★★★★★ (라이브)** — 5석 한정 행사(Event 9)를 만들어 공개하고, 9명이 몰리자 **정확히 5명까지 발급되고 나머지는 마감** 안내를 받았다. 온체인: Event 9 tier `minted 5/5`, Ticket id 14–18. (첫 시도는 페이마스터 deposit 고갈로 공개 op 가 안 실려 Draft 잔류 → deposit 충전 후 재실행에서 통과.)
- **승인 관리(신청 관리) ★★☆ (부분·미완)** — 승인 행사(Event 7)는 공개됐고 신청도 **온체인에 실제로 접수**된다(ClaimRequest 4건 Pending: 관객 02–05). 그러나 신청 뒤 **화면이 대기 상태를 제때 못 띄워**(인덱서 지연 + 신청은 클레임과 달리 재폴링이 없음) 하니스가 신청 단계에서 막혀 **선택 승인/전체 승인 화면까지 도달하지 못했다.** 승인 자체의 결함이 아니라 신청→대기 표시의 지연이 원인.

## 총평
라이브 4까지 남았던 **연속 티켓 발급 불안정이 이번에 완전히 해소**됐다(관객 리뷰 참조). 주최자 여정은 가입→탐색→만들기→**공개**→마감까지 끝까지 라이브 통과했고, 유료는 정직 차단, 마감은 5/5로 정확하다. 남은 한 지점은 **승인 신청의 대기 상태가 화면에 늦게 뜨는 것**(신청은 온체인 접수되지만 인덱서 지연 + 신청 재폴링 부재). 운영 측면에선 **페이마스터 deposit(3.65 MON)이 6개 시나리오 한 판(약 20+ 스폰서 op)을 채 못 버티고 0.31 MON까지 빠져** 후반 op(마감 공개·후반 신청)를 막았다 — 충전 후 정상화.
