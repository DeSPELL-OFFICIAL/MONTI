# 관리자 리뷰 — 페르소나 …01 "관리자 몬티" (라이브 2, 2026-09-27)

대상: 프로덕션 `https://monti.despell.io` (신규 배포). 별점 1–5. (라이브)=실제 관찰.

> 작은 크루로 무료 모임 티켓을 나눠주려는 주최자. 폰(390px)에서 진행.

## 단계별 별점

- **가입 ★★★★☆ (라이브)** — 이번엔 그림 캡차 없이 번호 → 코드 → `계정 만들기` 한 번으로
  잠금·휴대폰 등록·신원 등록까지 매끄럽게 끝났다(테스트 번호 우회 적용). 재방문 로그인은 얼굴/지문
  느낌으로 빠른데, **가끔 첫 시도가 "로그인하지 못했어요" 로 튕겨** 다시 눌러야 했다.
  > "가입은 깔끔. 근데 로그인이 한 번에 안 될 때가 있어 불안."
- **행사 탐색 ★★★★☆ (라이브)** — 깔끔한 라벤더 UI, 필터·검색·하단탭 정상. 공개 행사도 보인다.
- **행사 만들기 ★★☆☆☆ (라이브)** — 리디자인이 훌륭하다: **빠른 시작(무료 선착순/무료 관리자
  승인/유료 일반)** 프리셋 한 번에 티켓 종류가 정해지고, 티켓 그림이 실시간으로 미리보인다. 유료를
  고르면 "유료 티켓은 곧 열려요…" 로 정직하게 막아준다. 여기까지는 별 다섯.
  **그런데 `행사 만들기` 를 누른 뒤가 문제다.**
- **행사 발행/생성 ★☆☆☆☆ (라이브·치명)** — `행사 만들기` 를 누르면 "만드는 중이에요. 화면을
  나가도 돼요. 잠시 뒤 주최자 화면에서 확인해 주세요" 가 뜬 채 **7~8분을 기다려도 완료(행사 주소)
  화면으로 넘어가지 않았다.** 행사가 만들어졌는지, 링크가 뭔지 알 수가 없다. 발행도 "아직 확인
  중이에요" 에 머물러 새로고침해야 상태를 안다. 주최자 입장에서 가장 중요한 순간에 **끝을 못 본다.**
  > "만들기를 눌렀는데 몇 분째 '만드는 중'. 이게 된 거야 만 거야?"
- **승인 관리(승인 대기) ★★★☆☆ (라이브·부분)** — 신청 관리 화면(선택 승인/전체 승인)과 승인
  프리셋은 이제 존재한다. 다만 승인 행사 자체를 발행까지 못 가서(위 문제) 승인 흐름을 끝까지
  돌려보지 못했다.

## 총평
가입·탐색·생성 화면 설계는 확실히 좋아졌다(빠른 시작·실시간 티켓 그림). 그러나 **행사 생성의
온체인 확정이 몇 분이 지나도 끝나지 않아 주최자가 완료를 확인할 수 없는 것**이 치명적이다.
"행사를 만들 수는 있게 생겼는데, 만들어졌는지 알려주질 않는다."
