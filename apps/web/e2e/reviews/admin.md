# 관리자 리뷰 — 페르소나 …01 "관리자 몬티" (라이브 4, 2026-09-27)

대상: 프로덕션 `https://monti.despell.io` (스폰서 op 2×베이스 수수료 + 드롭/만료 op 재전송 반영본). 별점 1–5. (라이브)=실제 관찰.

> 작은 크루로 무료 모임 티켓을 나눠주려는 주최자. 폰(390px, 헤드리스 크로뮴)에서 진행.

## 단계별 별점

- **가입/로그인 ★★★★☆ (라이브)** — 재방문 패스키 로그인이 콜드에서도 첫 시도에 성공(중앙값 **7.1s**).
  라운드2 자동 재시도가 계속 붙어 지난 튕김이 재현되지 않았다.
- **행사 탐색 ★★★★☆ (라이브)** — 라벤더 UI, 필터·검색·하단탭 정상. 공개 행사·상세 정상.
- **행사 만들기(입력) ★★★★☆ (라이브)** — 이어서 작성 시트 → 포스터 올리기/크롭 → 제목·소개·시간·장소
  → 빠른 시작 프리셋 + 실시간 TicketArt 미리보기 → 주최자 이름까지 전 구간 완주.
- **행사 생성/발행(확정) ★★★★★ (라이브 · 지난 3회 블로커 해소!)** — 라이브 3까지 치명이던
  **createEvent 온체인 미채굴이 이번에 풀렸다.** `행사 만들기` 를 누르면 생성 op 가 실제로 블록에 실리고
  완료(행사 주소) 화면으로 넘어간다. 무료 선착순·관리자 승인 두 행사를 만들고 **발행까지** 마쳤으며, 유료는
  설계대로 정직 차단(`유료 티켓은 곧 열려요…` + 버튼 비활성). **온체인 증거**: 관리자 스마트계정
  `0x5DBdca2d…` 의 create/publish UserOperationEvent **3건 전부 success=true** — createEvent(무료+조직)
  op `0x5d9a4745…` @블록 65948554, createEvent(승인) `0x99b61cab…` @65948611, publish(승인)
  `0xd9201b41…` @65948638. 스폰서 페이마스터 `0xf73220b0…`, 번들러 tx `status=1`(effGasPrice **~102
  gwei**, 당시 베이스 ~100). 인덱서 `e6b82a8` 에 관리자 행사 4건(id 2–5) 등장.
  > "이제 진짜로 행사가 만들어진다. 지난번 '확인 중'만 돌던 게 끝났다."
- **승인 관리(신청 관리) ☆ (미도달)** — 관리자 승인 행사(Event id=5, `approvalRequired=true`)는 생성·발행됐지만,
  앞 시나리오(이용자 티켓 받기)가 실패하며 Playwright 워커가 재시작돼 공유 상태(이벤트 id)가 초기화됐고,
  신청 관리 화면까지 도달하지 못했다(제품 결함 아님 · 하니스 한계, friction-log 참고).

## 총평
**세 번 연속 뒤 흐름 전체를 막던 조직/행사 생성 op 미채굴이 이번에 해결됐다** — 스폰서 op 가 2×베이스
수수료로 실제 채굴되고 완료 화면까지 정상 진행된다. 주최자 여정(가입→탐색→생성→발행)이 처음으로 끝까지
라이브 통과했다. 유일하게 남은 온체인 과제는 주최자가 아니라 **이용자 티켓 받기 op 의 연속 안정성**
(첫 명 성공, 둘째부터 실패 — claim 에는 주최자 초안과 달리 드롭 재전송 경로가 없음)과, 한 시나리오가
실패하면 뒤 시나리오를 평가하지 못하는 하니스의 상태 공유 취약성이다.
