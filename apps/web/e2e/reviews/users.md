## 9명 종합
- **가입/로그인 ★★★★** — 패스키 재로그인 9명 전원 성공(중앙값 **7.1s**).
- **행사 탐색 ★★★★** — 디자인·정보구조 견고, 공개 행사·상세 정상.
- **티켓 받기 ★★★★★ (헤드라인·해소)** — **9명 전원 온체인 발급 성공**(무료 Event 6, tier `minted 9/9`, Ticket id 5–13, 각자 다른 스마트계정). 라이브 4의 "둘째부터 실패"가 **완전히 사라졌다** — Batch 1 자동 재전송(-32000 precheck backoff) + deposit 상향 + 가입 시 계정 선배포의 합작. 받기 중앙값 **4.0s**.
- **내 티켓 ★★★★** — 받은 티켓이 그림(TicketArt)과 함께 목록에 뜬다(중앙값 1.9s).
- **두 번 받기(한도) ★★★★★** — 같은 행사 재수령은 `이미 다 받았어요`로 버튼 비활성 + 안내. 정직.
- **마감 ★★★★★** — 5석에 9명, 앞 5명 발급(id 14–18) 뒤 나머지 `마감` 안내. 온체인 `minted 5/5`.
- **승인 대기 ★★☆ (부분)** — 신청은 **온체인 접수**(ClaimRequest Pending 4건)되지만, 신청 직후 **대기 상태가 화면에 늦게 떠**(인덱서 지연 + 신청 재폴링 부재) 승인까지 이어지는 흐름을 자동으로 확인하지 못함.

## 팀이 볼 단 하나
라이브 4의 "받기 연속 실패"는 **해결됐다.** 다음 한 지점은 **승인 신청의 대기 상태를 클레임처럼 재폴링**해 인덱서 지연에도 화면이 대기/승인 상태를 스스로 따라잡게 하는 것. 신청은 이미 온체인에 실린다.
